# CaineAI

Два ИИ-строителя, Кейн и Авель, соревнуются: каждый проектирует уровень,
строит его блок за блоком, а судят их жители — гуляки с эволюционировавшими
мозгами. У кого в карте живётся лучше, тот и взял раунд. Проигравший
перенимает лучшую планировку победителя.

Всё это видно в браузере: две платформы, стройка в реальном времени,
прогулка жителей и счёт матча.

## Что здесь на самом деле происходит

**Кейн не копирует шаблоны — он изобретает.** Уровень собирается из модулей
(вход, коридор, развилка, зал, башня, городской квартал), но сам словарь
модулей эволюционирует: Кейн придумывает новые элементы прямо во время
показа, и те, что приживаются в хороших картах, остаются.

**Оценка не рукописная.** По готовой карте гуляют шестнадцать агентов —
крошечные нейросети, выведенные эволюцией, а не обученные градиентом.
Насколько хорошо им живётся, и есть оценка карты. Она же двигает эволюцию
уровней: круг замкнут.

**Разнообразие — цель, а не побочный эффект.** Вместо поиска одного лучшего
уровня работает архив ниш (MAP-Elites): в нём живут полторы сотни непохожих
планировок, и каждая — лучшая в своей нише.

| Слой | Что делает | Чем реализовано |
|---|---|---|
| Архитектор | что строить | геном + MAP-Elites + сеть-проектировщик |
| Критик | хорошо ли вышло | симуляция жителей + метрики планировки |
| Руки | как построить | A\*, детерминированно |
| Жители | живут в уровне | нейроэволюция сетей на 244 числа |

```
Python: модули + критик + эволюция + FastAPI  ──HTTP──>  React + three.js
```

Подробный журнал разработки со всеми замерами и провалами — [DEVLOG.md](DEVLOG.md).
План — [ROADMAP.md](ROADMAP.md).

## Запуск

**Бэкенд:**

```bash
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --port 8000
```

**Фронтенд:**

```bash
cd frontend
npm install
npm run dev
```

Открыть http://localhost:5173

## Режимы работы

Задаются переменными окружения перед запуском бэкенда:

| Переменная | Значения | По умолчанию | Что делает |
|---|---|---|---|
| `CAINE_MODE` | `build` / `legacy` | `build` | `build` — Кейн проектирует карту и строит её. `legacy` — старый DQN на шести зашитых паттернах, только для сравнения «до/после» |
| `CAINE_STYLE` | `random` / `hybrid` / ключ стиля | `random` | `random` — 60% чистых стилей, 40% гибридов. `hybrid` — только гибриды. Ключи: `cave`, `castle`, `mansion`, `island`, `circus`, `candy` |
| `CAINE_TEMPO` | мс | `150` | Подсказка фронтенду, как часто запрашивать шаг |
| `CAINE_AUTO` | `0` / `1` | `0` | `0` — достроив карту, Кейн ждёт кнопки «Построить новую». `1` — сразу начинает следующую |
| `CAINE_BATCH` | `auto` / число | `auto` | Блоков за кадр. `auto` подбирает так, чтобы любая карта строилась примерно за одно и то же время |
| `CAINE_FRAMES` | число | `1600` | Целевое число кадров на карту при `auto` (≈4 минуты при темпе 150 мс) |
| `CAINE_SOURCE` | `auto` / `designer` / `archive` / `grammar` | `auto` | Откуда брать карты: `archive` — то, что Кейн нашёл эволюцией, `grammar` — рукописные правила, `auto` — архив, если он есть |
| `CAINE_ELITE_TOP` | 0..1 | `0.5` | Какую долю лучшей части архива показывать |

```powershell
$env:CAINE_STYLE="circus"     # только цирк
$env:CAINE_MODE="legacy"      # старый DQN для сравнения
```

## Обучение

```bash
cd backend
python train_dqn.py
```

Дообучает `caine_dqn.pth` (веса, оптимизатор, epsilon, счётчик шагов).
Обучение и показ намеренно разделены.

## API

| Эндпоинт | Что возвращает |
|---|---|
| `GET /step` | Один кадр: `kind` (`move` / `place` / `decor` / `idle` / `miss`), позиция Кейна, `blocks`, `decor`, `progress`, `map_done`, `awaiting`, `world_reset`, `level` |
| `GET /level` | Текущая карта: стиль, палитра, настроение и цвет неба, габариты, дескриптор, новизна, уже построенное |
| `GET /next` | Спроектировать новую карту (кнопка «Построить новую») |
| `GET /stats` | Режим, стиль, прогресс достройки, дескриптор |
| `GET /config` | Режим, темп, список стилей, размер карты |

Схема кадра одинакова для обоих режимов, поэтому фронтенду не нужно знать,
какой движок за ним стоит.

Координаты уже сдвинуты так, чтобы карта 78×78 была отцентрована на поле.

## Известные проблемы


- Гуляки бродят случайно, интеллекта у них нет — Фаза 3.
- `genetic.py` мёртвый: падает (`GRID_SIZE=7` при паттернах 6×6) и нигде
  не подключён. Заменён на `genome.py`, удалить.
- Режим `legacy` унаследовал баги старого движка: в Особняке ставится
  0 блоков (цвета 6 и 8 недостижимы), в Пещере точность ~45%. Не чинятся
  намеренно — это экспонат «до».

## Текстуры блоков

Файлы кладутся в `frontend/public/tex/` с именами `<стиль>_<роль>.png`:

```
cave_wall.png    cave_floor.png    cave_accent.png
castle_wall.png  castle_floor.png  castle_accent.png
mansion_...  island_...  circus_...  candy_...  city_...
```

Всего 21 файл, **64×64** (рисуются 16×16 и увеличиваются по-пиксельно,
как в майнкрафте), PNG, бесшовные. Перерисовать набор целиком:

```bash
cd backend && python make_textures.py
```

**Цвет палитры не умножается на текстуру, а подкрашивает её.** Текстуры
цветные, поэтому умножение превратило бы их в грязь. Вместо этого палитра
переносится в режиме «цвет»: рисунок и светотень остаются от текстуры,
оттенок берётся от карты. Сила подкраски — `TINT` в `textures.js`.

Благодаря этому на бэкенде не изменилось ничего: палитры мутируют, критик
меряет их контраст и насыщенность, гибриды смешивают цвета — текстуры в это
не вмешиваются.

Гибрид смешивает фактуры в тех же долях, в каких смешал цвета: карта несёт
свой состав (`style_mix`), и текстуры сводятся по нему.

Файла может не быть — тогда блок рисуется сплошным цветом, как до текстур.

## Интерфейс

Шрифт Rubik Spray Paint лежит локально в `frontend/public/fonts/` — показ
не должен зависеть от интернета.

Сверху две мультяшные кнопки строителей (красный Caine, синий Abel) со счётом
между ними, под каждой — тема его текущей постройки. Кнопка внизу одна на
двоих: раунд общий, поэтому и новая стройка запускается сразу у обоих.
Появляется, когда закончили оба — начать заново у одного, пока второй ещё
строит, значило бы выбросить его недостроенную карту. В углу — чат пузырями: реплики Кейна
красные, Авеля синие.

Посмотреть экран итога, не играя матч целиком:
`?victory=caine`, `?victory=abel`, `?victory=draw`.
Готовые снимки лежат в `preview/`.

Матч идёт **из пяти раундов** (`MATCH_ROUNDS` в `duel.py`). По окончании
наплывает красный экран итога: счёт, чемпион и кнопка «Играть снова».
Значок победителя намеренно не нажимается — это награда, а не орган
управления.

Стили лежат в `src/ui.css`. Обводка текста сделана слоёной тенью, а не
`-webkit-text-stroke`: толстый штрих слипал мелкие брызги этого шрифта
и выглядел рваным.

## Свет, тени, bloom

Сцена рисуется с тенями от направленного «солнца», градиентным небом
(`Sky.jsx`) и постобработкой: bloom по яркому, лёгкая виньетка, сглаживание.
Тональная компрессия — ACES.

Порог bloom высокий намеренно: при низком расплывается вся постройка,
а пиксельные текстуры превращаются в кисель.

Всё это стоит примерно втрое по кадрам. Если машина не тянет — адрес
`?plain=1` выключает тени и постобработку, остальное работает как обычно.

## Авель: соперник (Фаза 4)

Два строителя на двух платформах, с раздельными архивами и разными вкусами.
Раунд считается, когда оба достроили: по обеим картам гуляют **одни и те же**
гуляки, и где им живётся лучше, тот и выиграл. Проигравший забирает лучшую
планировку победителя себе в архив.

```bash
cd backend
python -c "import random; from archive import Archive; from evolve import seed, run; import modgen; modgen.load(); a=Archive('archive_abel.json'); r=random.Random(42); seed(a,r,bias=['city','island','candy','castle']); run(6000,archive=a,rng=r); a.save('archive_abel.json')"
```

Выключается через `CAINE_DUEL=0` — тогда остаётся один Кейн, как раньше.

**Камера.** Только поворот вокруг платформы и приближение: сдвиг выключен,
угол подъёма ограничен. Переключение между платформами — кнопками сверху
слева, камера переезжает плавно и сохраняет твой угол.

## Живое изобретение

Кейн продолжает придумывать, пока строит: фоновый поток мутирует карты,
пополняет архив и время от времени изобретает новый модуль. Следующая карта
уже может его использовать.

```powershell
$env:CAINE_EVOLVE="1"
python -m uvicorn main:app --port 8000
```

| Переменная | Смысл | По умолчанию |
|---|---|---|
| `CAINE_EVOLVE` | включить живое изобретение | `0` |
| `CAINE_EVOLVE_DUTY` | доля процессора у фонового потока | `0.5` |

Выключено по умолчанию намеренно: во время записи видео меняющийся под тобой
архив мешает переснять дубль. Архив и словарь связаны: карта ссылается на модули по имени,
поэтому эти два файла надо переносить вместе. Если модуль всё же пропал,
архив выбросит ссылающиеся на него карты, а не упадёт.

Чтобы Кейн учитывал ваш вкус, положите понравившиеся картинки
в `backend/references/` — они станут положительными образцами.
