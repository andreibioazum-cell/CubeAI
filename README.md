# CaineAI

Два ИИ-строителя, Кейн и Авель, соревнуются: каждый проектирует уровень,
строит его блок за блоком, а судят их жители — гуляки с эволюционировавшими
мозгами. У кого в карте живётся лучше, тот и взял раунд. Проигравший
перенимает лучшую планировку победителя.

Всё это видно в браузере: две платформы, стройка в реальном времени,
прогулка жителей и счёт матча из пяти раундов.

**Сервер не нужен.** Python работает прямо во вкладке через WebAssembly,
поэтому у каждого зрителя своя стройка, свой архив и свой счёт — а сайт
можно положить на любой статический хостинг.

---

## Что здесь происходит

**Кейн не берёт готовые шаблоны — он изобретает.** Уровень собирается из
модулей (вход, коридор, развилка, зал, башня, городской квартал), но сам
словарь модулей эволюционирует: новые элементы придумываются, испытываются
и остаются, если приживаются в хороших картах.

**Оценка не рукописная.** По готовой карте гуляют шестнадцать агентов —
крошечные нейросети на 244 числа, выведенные эволюцией, а не обученные
градиентом. Насколько хорошо им живётся, и есть оценка карты. Она же двигает
эволюцию уровней: круг замкнут.

**Разнообразие — цель, а не побочный эффект.** Вместо поиска одного лучшего
уровня работает архив ниш (MAP-Elites): в нём живут полторы сотни непохожих
планировок, и каждая — лучшая в своей нише.

**Названия стилей найдены, а не заданы.** «Кольцевая короткая галерея» —
это имя кластера, который нашёлся в архиве сам; родословная («Особняк ×
Цирк») показывается мелким шрифтом рядом.

| Слой | Что делает | Чем реализовано |
|---|---|---|
| Архитектор | что строить | геном + MAP-Elites + сеть-проектировщик |
| Критик | хорошо ли вышло | симуляция жителей + метрики планировки |
| Руки | как построить | A\*, детерминированно |
| Жители | живут в уровне | нейроэволюция сетей на 244 числа |
| Соперничество | кто сильнее | общие судьи, проигравший крадёт планировку |

## На чём написано

**Расчётная часть — Python.** Никакого фреймворка глубокого обучения в
показе не участвует: эволюция, критик и мозги гуляк — это numpy и обычные
списки. Поэтому всё и помещается в браузер.

| Библиотека | Зачем |
|---|---|
| [numpy](https://numpy.org) | мозги гуляк и симуляция прогулок на массивах |
| [Pyodide](https://pyodide.org) | CPython, собранный в WebAssembly: весь Python работает во вкладке |
| [PyTorch](https://pytorch.org) | только для обучения сети-проектировщика, в показе не нужен |
| [FastAPI](https://fastapi.tiangolo.com) + [uvicorn](https://www.uvicorn.org) | необязательный режим с сервером, удобен при разработке |
| [Pillow](https://python-pillow.org) | генерация текстур блоков |

**Показ — React и WebGL.**

| Библиотека | Зачем |
|---|---|
| [React](https://react.dev) | интерфейс |
| [three.js](https://threejs.org) | трёхмерная сцена |
| [@react-three/fiber](https://r3f.docs.pmnd.rs) | three.js как React-компоненты |
| [@react-three/drei](https://drei.docs.pmnd.rs) | камера, орбита, загрузчики моделей |
| [@react-three/postprocessing](https://react-postprocessing.docs.pmnd.rs) | bloom, виньетка, сглаживание |
| [Vite](https://vite.dev) | сборка |

Тысячи блоков рисуются инстансингом — один вызов отрисовки на пару
«форма + цвет», иначе сцена на семь тысяч кубов не двигалась бы.

## Запуск

```bash
cd frontend
npm install
npm run build
```

Готовая папка `frontend/dist` — обычный статический сайт. Кладётся куда
угодно: Netlify, GitHub Pages, шаред-хостинг, itch.io. Запускать на стороне
хоста нечего.

Посмотреть локально:

```bash
cd frontend/dist && python -m http.server 8899
```

Первое открытие — около 9 секунд и 17 МБ: браузер качает Python и numpy.
Дальше страница поднимается из кеша.

### Режим с сервером

Нужен только при разработке: правку в Python видно после перезапуска
uvicorn, без пересборки и без повторной загрузки Python в браузер.

```bash
cd backend && pip install -r requirements.txt
python -m uvicorn main:app --port 8000
```

```powershell
cd frontend
$env:VITE_API="http://127.0.0.1:8000"
npm run dev
```

## Что можно покрутить

Адресом страницы:

| | |
|---|---|
| `?plain=1` | без теней и постобработки — если машина не тянет |
| `?fancy=1` | вернуть красоту на телефоне, где она выключена по умолчанию |
| `?props=1` | каталог придуманного реквизита крупным планом |
| `?victory=caine` | экран итога матча, не играя пять раундов |

Переменными окружения при запуске сервера — стиль, темп, источник карт,
живое изобретение во время показа. Список в начале `backend/world.py`.

## Как получены архивы

Кейн и Авель приходят с готовой памятью: `archive.json` и `archive_abel.json`
собраны заранее. Пересобрать или продолжить:

```bash
cd backend
python evolve.py 6000            # эволюция карт, ~4.5 минуты
python evolve_modules.py 6       # придумать и отобрать новые модули
python evolve_props.py 8000      # придумать реквизит
python evolve_walkers.py 40      # вывести мозги гуляк, ~25 минут
python make_textures.py          # перерисовать текстуры блоков
```

Обучение сети-проектировщика (единственное место, где нужен PyTorch):

```bash
python collect_corpus.py 24000   # набрать корпус эволюцией
python train_designer.py 40 0.75 # обучить на верхнем квартиле
```

Архив и словарь модулей связаны: карта ссылается на модули по имени,
поэтому переносить их надо вместе.

## Структура

```
backend/
  modules.py      словарь модулей: вход, коридор, зал, башня, квартал
  levelgen.py     грамматика: связная карта, стили, гибриды
  genome.py       геном карты, мутации, скрещивание
  archive.py      архив MAP-Elites — память строителя
  critic.py       оценка карты: жители, структура, штрафы за вырождение
  walkers.py      жители: крошечные сети и симуляция прогулок
  hands.py        руки: маршрут и укладка блоков по чертежу
  modgen.py       изобретение новых модулей
  props.py        изобретённый реквизит
  styles_found.py стили как найденные кластеры
  duel.py         соперничество: судейство, счёт, кража планировок
  world.py        строитель: карта, архив, платформа — без сети
  web_engine.py   те же маршруты прямым вызовом из браузера
  main.py         те же маршруты по HTTP (необязательный сервер)

frontend/src/
  App.jsx         сцена и состояние мира
  engine.js       мост к Python: Pyodide во вкладке либо HTTP к серверу
  useBuilder.js   состояние одного строителя
  Blocks.jsx      инстансинг блоков
  Walkers.jsx     жители в кадре
  framing.js      с какой стороны и как далеко ставить камеру
  Boot.jsx        экран, пока Python едет в браузер
  Victory.jsx     экран итога матча
```

## Мелочи, которые оказались важными

**Цвет палитры не умножается на текстуру, а подкрашивает её.** Текстуры
цветные, умножение превратило бы их в грязь. Палитра переносится в режиме
«цвет»: рисунок и светотень остаются от текстуры, оттенок берётся от карты.
Благодаря этому эволюция палитр продолжает работать как раньше.

**Камера сама выбирает сторону захода.** Поле зрения задаётся по вертикали,
поэтому на телефоне в портретной ориентации узким местом становится ширина.
Камера смотрит вдоль длинной стороны постройки — длина уходит в глубину
кадра и ложится на высоту экрана.

**Ничья — законный исход.** Если карты разошлись меньше чем на `MARGIN`
(`duel.py`), победа не засчитывается никому: раунд сыгран, счёт не
изменился. Под кнопкой раунда написано, чем он кончился, — иначе такой раунд
неотличим от поломки.
